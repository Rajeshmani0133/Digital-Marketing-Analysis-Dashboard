# Digital Marketing Analysis | Power BI

## Project Overview
This project focuses on analyzing digital marketing data using Microsoft Power BI. The dashboard is designed to help explore marketing performance, compare available metrics, and understand campaign or channel trends in the dataset.

## Objectives
- Analyze digital marketing performance.
- Compare key marketing metrics across available categories.
- Identify high-performing and low-performing areas.
- Track trends in marketing data.
- Present findings through interactive visualizations.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning and Transformation
- Data Modeling
- Data Visualization

## Dashboard Features
- KPI cards for important marketing metrics available in the dataset.
- Comparative charts for marketing performance.
- Category-wise analysis of available marketing data.
- Trend analysis where date fields are available.
- Interactive filters and slicers, where implemented.

## Key Skills Demonstrated
- Data cleaning and transformation
- KPI tracking
- DAX calculations
- Data visualization
- Comparative and trend analysis
- Interactive dashboard development

## How to View the Project
1. Download the `Digital Marketing Analysis.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Explore the report pages, charts, and filters.

## Files Included
- `Digital Marketing Analysis.pbix` — Power BI dashboard file
- `README.md` — Project documentation

## Conclusion
This project demonstrates how Power BI can help organize digital marketing data into an interactive report that supports performance monitoring and data-driven decision-making.
